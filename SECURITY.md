# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SeekLink, please report it
privately. Publicly disclosing a security issue before it is fixed can
put users at risk.

**Email:** [simonsun990@gmail.com](mailto:simonsun990@gmail.com)

Please include:

- A description of the issue and its potential impact.
- Steps to reproduce the issue, if possible.
- Any suggested fix or mitigation, if you have one.

I will acknowledge your report within 48 hours and aim to publish a fix
before public disclosure. Thank you for helping keep SeekLink's users
safe.

## Supported Versions

Only the latest released version of SeekLink receives security fixes.
